# 📊 Road Accident Data Analysis in Microsoft Excel

An interactive **Road Accident Data Analysis Dashboard** built entirely in **Microsoft Excel**. This project analyzes road accident data to identify trends, casualty distribution, vehicle involvement, road conditions, and other key insights using Pivot Tables, Pivot Charts, Slicers, and Excel Dashboard techniques.

---

## 📌 Project Overview

The objective of this project is to transform raw road accident data into meaningful business insights through an interactive Excel dashboard.

The dashboard enables users to analyze accident statistics, identify high-risk conditions, and make data-driven decisions using dynamic filters and visualizations.

---

## 🚀 Features

- Interactive Excel Dashboard
- Dynamic Slicers for filtering data
- KPI Cards for quick insights
- Pivot Tables & Pivot Charts
- Monthly Accident Trend Analysis
- Casualty Severity Analysis
- Vehicle Type Analysis
- Road Type Analysis
- Road Surface Condition Analysis
- Light Condition Analysis
- Urban vs Rural Comparison
